# Research notes

These notes are background analysis, not Pi Cloud product truth. They may
describe upstream projects, rejected options or assumptions that changed after
the note was written. Always resolve a conflict in favor of `README.md`,
`docs/ARCHITECTURE.md` and the current ADR index.

Worker affinity, gVisor as the runtime, S3 conversation checkpoints and Kopia
Workspace copies—has been removed from the current tree and remains available
through Git history.
